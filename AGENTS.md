# Agent working agreement

Read `.agent/README.md` and `.agent/memory/project.md` before making changes. The **Standing product conventions** in `.agent/memory/project.md` are mandatory for every page and module (audit logging, light/dark themes, top navigation with dropdowns, column-wise storage only (no JSON columns), pagination 20/50/100, easy + advanced + date-range filters, xlsx/csv import and export + PDF export, module dashboards, Navy Blue & White enterprise theme without animations/emojis, alerts near the data, RBAC by default). Keep durable decisions in `.agent/memory/project.md` and regenerate the import graph with `make graph` after structural changes. Use `.agent/skills/` for focused workflows. Do not commit credentials, generated databases, virtual environments or build output. Test backend and build frontend before delivering. Do not silently change authorization semantics or tenant boundaries.
